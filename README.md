# Chave dicotónica - LAB

Ferramente web que ajuda a identificar o género de um videiojogo com uma chava dicotómica.

Projeto de Laboratório de Informática, Licenciatura em Engenharia Informática Aplicada, ESTGA-UA.

O ulilizador vê a descrição de um cenário de jogabilidade ( sem o nome nem o género ), responde a pergunas de sim o não
