# Chave dicotónica - LAB

Ferramente web que ajuda a identificar o género de um videiojogo com uma chava dicotómica.

Projeto de Laboratório de Informática, Licenciatura em Engenharia Informática Aplicada, ESTGA-UA.

O ulilizador vê a descrição de um cenário de jogabilidade ( sem o nome nem o género ), responde a pergunas de __*sim*__ o _**não**_ e a chave leva-o a um dos 16 géneros. No fim da sessão vê estatísticas e pode exportar os resultados.

## Como usar
* **Sem instalar nada**: abre ```index.html``` no navegador.
* **Em desenvolvimento**: ```npm start``` e abre <https://.....>
* **Testes**: ```npm test``` (Node 20 ou superior, sem dependências).
